# Pushpank Kumar — Moonlit Botanical Developer Portfolio

> A premium, immersive developer portfolio hidden inside a moonlit digital botanical garden.

---

## 🌿 Concept

This is not a template. This is an **experience**.

The portfolio is designed as an **immersive digital botanical garden** — elegant, mysterious, calm, and slightly magical. It combines the feel of a luxury editorial website, botanical photography, and a modern developer portfolio, all wrapped in cinematic moonlight and glassmorphism.

**Tagline:**
*"A developer portfolio hidden inside a moonlit botanical garden."*

---

## 🎨 Visual Language

| Element | Description |
|--------|-------------|
| **Primary Colors** | Deep forest green, emerald, moss, sage, dark charcoal, soft cream |
| **Accents** | Subtle white glass, very subtle gold/moonlight |
| **Textures** | Realistic flowers, leaves, petals, vines, atmospheric particles |
| **Surfaces** | Frosted glass panels, translucent layers, soft reflections |
| **Lighting** | Cinematic gradients, ambient moonlight, depth of field |
| **Forbidden** | Neon green, cartoon flowers, anime aesthetics, generic SaaS layouts |

## ✨ Key Features

### 🌙 Hero — 3D Botanical Environment
- Full-screen immersive 3D scene with realistic flowers, leaves, and petals at varying depths
- Subtle parallax based on mouse position
- Gentle floating, rotating, and drifting animations
- **Large realistic moon** that descends from above the viewport on load, then rotates almost imperceptibly
- Falling particles: glowing dust, petals, tiny leaves
- Central focus: **"PUSHPANK"** in an elegant editorial serif, with a clean sans-serif for supporting text
- Two CTAs: *Explore My Work* and *Let's Connect* — glassmorphic, magnetic hover

### 🧊 Glassmorphism
Selective, elegant use of frosted glass:
- `backdrop-filter: blur(20px)`
- `background: rgba(255, 255, 255, 0.06)`
- `border: 1px solid rgba(255, 255, 255, 0.12)`
- Soft inner highlights, gentle shadows, subtle reflections

### 🧭 Navigation
- Floating glass navbar with rounded corners and thin border
- Links: Home · About · Projects · Skills · Contact
- On scroll: shrinks, increases blur, becomes slightly more opaque
- Mobile: clean animated menu

### 🖱️ Hero Interaction
- Flowers and leaves react to cursor movement with subtle parallax
- Glass cards tilt gently in 3D
- Buttons have magnetic hover behavior
- Petals respond to pointer movement
- Full `prefers-reduced-motion` support

### 📜 Scroll Experience
Scroll-driven, artistic animations — not just fade-ins:
- Parallax, horizontal movement, scale transitions
- Blur-to-focus, mask reveals, text splitting
- Botanical elements moving across sections
- Flowers growing and blooming
- Sticky storytelling sections

### 🌱 About Section
- **Left:** Personal information (natural, concise, no exaggeration)
- **Right:** A decorative botanical glass frame with realistic leaves, small flowers, vines, and moonlight
- Inside the frame: a clear `[YOUR PHOTO]` placeholder, easy to replace
- Hover: flowers move, frame tilts, glass reflection sweeps across

### 🌿 My Journey — Botanical Timeline
- A **vine** serves as the timeline
- Each milestone appears as a **flower blooming** along the vine
- Years: 2025, 2025–2026, 2026, Present

### 🌸 Skills Garden
- No progress bars, no fake percentages
- Technologies represented as **interactive floating glass botanical cards**
- Categories: Frontend, Programming, Tools, Concepts
- Hover: card rotates slightly, botanical element reacts, subtle glow appears

### 🏡 Projects — Bento Greenhouse
- Sophisticated **Bento Grid** inspired by a botanical greenhouse
- Cards of different sizes: large featured, medium, small experiments
- Each card: project name, short description, technologies, GitHub link, live demo link
- **Click to expand** into a larger glass panel with a smooth FLIP-style transition
- Expanded view: title, description, tech stack, features, GitHub, live demo, preview image
- Subtle 3D tilt, glass reflection, moving botanical shadows
- **Featured project** gets a large card with a floating glass browser window preview

### 🐙 GitHub Connection
- Section: *"More experiments live on GitHub."*
- Button: **Visit GitHub** → [github.com/itspushpank](https://github.com/itspushpank)
- Small GitHub icon, botanical visual language

### 🌙 Contact — Botanical Night Garden
- Title: **"Let's Grow Something."**
- Supporting text: *"Have an idea, project, collaboration, or simply want to connect? I'd love to hear from you."*
- Fields: Name, Email, Message
- Submit: **"Send Message"**
- On focus: border softly illuminates, small botanical animation, glass reflection moves
- On success: a small flower blooms as a success animation
- Social links: GitHub, Instagram, LinkedIn, Email (only if available)

### 🌑 Footer
- Minimal, elegant, fades into the dark green botanical background
- **PUSHPANK**
- *"Built with curiosity, code & a little moonlight."*
- GitHub · Instagram · LinkedIn

## 🛠️ Tech Stack

| Layer | Tools |
|-------|-------|
| **Framework** | React |
| **3D** | Three.js / React Three Fiber |
| **Animation** | GSAP, Framer Motion |
| **Styling** | CSS (glassmorphism, custom properties) |
| **Scroll** | Smooth scrolling, scroll-driven animations |
| **Performance** | Lazy loading, compressed textures, limited particles, GPU-friendly animations, `requestAnimationFrame` |
| **Accessibility** | Semantic HTML, keyboard nav, visible focus states, reduced-motion support |
